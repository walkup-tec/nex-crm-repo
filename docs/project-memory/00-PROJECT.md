# NEX Ads

SaaS multiempresa da NEX Marketing Digital. O cliente acompanha campanhas Meta, saldo, financeiro, criativos e usuários. A operação interna usa a área Master.

## Stack

- TanStack Start, React 19, Vite 8, Tailwind CSS 4
- Supabase (autenticação, Postgres com RLS, storage)
- Migrações em `drizzle/migrations`
- Servidor de produção: Nitro, preset `node-server` na VPS
